# Changelog

## 0.1.0

- Initial Devil Mail Client PWA foundation.
- Named mail tabs with add, rename, and close.
- Browser-style toolbar with local URL history and external browser fallback.
- Persistent local workspace.
- Optional CORS JSON unread monitoring with baseline/new-mail detection.
- Desktop notification support while the workspace is running.
- Workspace import/export and reset.
- GitHub Pages deployment workflow and dependency-free CI checks.
- HTTPS URL validation and static security headers.
