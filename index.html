Desktop browser · version 0.3.0

A real browser.
Not an iframe.

The old web workspace could not reliably open mail providers because they block iframe embedding. Devil Browser is being rebuilt as a desktop Chromium-based app, with actual page views, persistent sessions and browser controls.

Get a test build ↗ Published releases ↗

For a test build, open the latest successful Desktop Browser CI run in Actions and download the artifact for your operating system. Linux, Windows and macOS are built separately.

Devil Browser is a desktop app, so this information page cannot itself become the browser. Chrome extensions, Google Sync and direct Gmail/Microsoft Graph OAuth monitoring are not implemented yet. Some websites may still reject Electron-based browsers.
